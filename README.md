# AI-Learning-Plan 从零开始学习AI计划

## 第一阶段 AI认知与工具

### Week 1 AI到底是什么

资源：Coursera 《AI For Everyone》


本周目标：什么是机器学习、监督学习、好的数据，AI能做什么，不能做什么


| 课程 | 主要内容 |
| --- | --- |
| 1. Week 1 Introduction | 介绍人工智能的发展、AI 为什么重要，以及本课程的学习目标。 |
| 2. Machine Learning | 机器学习的基本概念：计算机如何从数据中学习规律，而不是完全依赖人工编写规则。 |
| 3. What is Data? | 什么是数据、训练数据和数据标签。为什么数据质量和数量会影响 AI 的表现。 |
| 4. The Terminology of AI | 解释 AI、机器学习、深度学习、神经网络、数据科学等术语之间的关系。 |
| 5. What Makes an AI Company? | 什么样的公司可以称为 AI 公司？数据、算法、技术人才和业务场景如何结合。 |
| 6. What Machine Learning Can and Cannot Do | 机器学习擅长什么、不擅长什么，理解 AI 的能力边界。 |
| 7. More Examples of What ML Can and Cannot Do | 通过更多实际案例，认识机器学习的适用条件和局限。 |
| 8. Non-technical Explanation of Deep Learning (Part 1) | 不用数学公式理解深度学习和神经网络。 |
| 9. Non-technical Explanation of Deep Learning (Part 2) | 进一步理解神经网络如何通过训练学习复杂模式。 |


### Week 2 全景认知

本周目标：清晰AI领域各种名词的关系，了解AI的“周边”

整理 AI|机器学习|深度学习|大模型 等等名词的关系图

### Week 3 AI Projects

这一周从认识 AI 转向理解 AI 项目是怎样真正落地的。

需要真正理解：
- 一个 AI 产品从想法到实际应用，需要经过哪些步骤？
- 训练一个 AI 模型需要什么？
- Machine Learning Project 和 Data Science Project 有什么区别？
- 为什么不是所有问题都应该用 AI 解决？
- 一个成功的 AI 项目需要哪些角色参与？

| 课程 | 主要内容 |
| --- | --- |
| 1. Week 3 Introduction | AI 项目的整体流程和本周学习目标。 |
| 2. Workflow of a Machine Learning Project | 机器学习项目的工作流程：确定问题、收集数据、训练模型、评估模型、部署应用。 |
| 3. Workflow of a Data Science Project | 数据科学项目的工作流程：数据收集、分析、发现规律、形成业务决策。 |
| 4. Every Job Function Needs to Learn How to Use Data | 为什么企业中的每个岗位都应该具备数据思维。 |
| 5. How to Choose an AI Project (Part 1) | 如何判断一个问题是否适合用 AI 解决，识别真正有价值的应用场景。 |
| 6. How to Choose an AI Project (Part 2) | 如何评估项目的可行性、成本、收益和实施难度。 |
| 7. Working with an AI Team | 如何与 AI 工程师、数据科学家、产品经理等团队成员合作。 |
| 8. Technical Tools for AI Teams（选修） | 了解 AI 团队常用的技术工具和开发环境。 |

### Week 4 AI and Society（人工智能与社会）
未来与社会影响

1. AI 对社会产生的影响。

2. Discrimination / Bias	AI 偏见与歧视：训练数据中的偏见如何影响 AI 决策。
   
3. Adversarial Attacks on AI	对抗性攻击：为什么一些经过精心设计的输入可能欺骗 AI 系统。

4. AI and Jobs	AI 对就业、职业结构和未来工作方式的影响。

5. Conclusion	总结课程，思考人工智能时代人类应该如何参与和适应。
